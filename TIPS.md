# Tips — CPS Referral Search Tool

## 1. Search by keyword or filter
Use the **search box** or **filters** (insurance, location, specialty, etc.) — e.g. **Bronx**, **Aetna**, **DBT**.  
Make sure provider **descriptions include keywords** staff will search.

## 2. Limit who can edit
Only **1–2 editors** should have the Editor login. They keep the list accurate and up to date — and try to incorporate feedback from staff.

## 3. Keep descriptions clean
Staff cannot edit the directory directly. Editors add updates at the **top of Description** — include the info, who contributed it, and the date.

```
--- NOT accepting new clients (Sally S., 7/8/2026) ---

[older description text]
```

# Tips — CPS Referral Search Tool

## 1. Search by keyword
Use the search box for locations, insurance, specialties — e.g. **Bronx**, **Aetna**, **DBT**.  
Make sure provider **descriptions include keywords** staff will search.

## 2. Limit who can edit
Only **1–2 editors** should have the Editor login. They keep the list accurate.

## 3. Keep descriptions clean
Put **new updates at the top**. Sign name + date. Older info stays below.

```
--- NOT accepting new clients (Sally S., 7/8/2026) ---

[older description text]
```

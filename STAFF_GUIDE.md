# Staff Guide — CPS Referral Directory

**Live site:** https://qishi0314-hash.github.io/Referral/

This guide is for CPS staff who use the referral directory day to day. No technical setup required.

---

## Getting started

1. Open the link above in any browser (Chrome, Safari, Firefox, Edge).
2. Use the **Filters** panel on the left to narrow providers by:
   - Insurance
   - Licensed state (e.g. NY, NJ)
   - Provider type
   - Session format (in-person / virtual)
   - Specialties
3. Use the **Search** box for name, address, or keywords.
4. Click a **provider card** to see full details, contact info, and websites.

---

## Staff login (notes)

1. Click **Staff login** (top right).
2. Enter the **staff access code** from your supervisor.
3. Enter your name in the **Your name for comments** field (e.g. `Sally S.`).
4. Open a provider → scroll to **Staff notes** → add a note.

Notes are shared with all CPS staff when cloud sync is enabled.

---

## Editor login (leads / admins only)

Use the **editor access code** to unlock extra tools:

| Action | How |
|--------|-----|
| Add a new provider | **+ Add provider** (top right) |
| Edit any field | Open provider → **Edit provider** |
| Remove a provider | Open provider → **Delete provider** → confirm |
| Delete a staff note | Open provider → **Delete** next to the note → confirm |

After login, the header shows **Editor mode** (not Staff mode).

---

## Tips

- **Hard refresh** if something looks outdated: `Ctrl+Shift+R` (Windows) or `Cmd+Shift+R` (Mac).
- **Licensed state filter** — useful when a student needs a provider licensed in a specific state.
- **Sliding Scale** appears under Insurance when cost is a concern.
- Do not share the **editor code** with all staff; keep it for leads who maintain the list.

---

## Problems?

| Issue | What to try |
|-------|-------------|
| Can't log in | Check you're using the correct code; ask your supervisor |
| Notes don't sync | Hard refresh; ask admin to verify Google Sheets setup |
| Can't edit providers | You need the **editor code**, not the staff code |
| Provider missing | Ask an editor to add them, or check filters |

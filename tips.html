Tips

CPS Referral Search Tool — quick guide for staff

1

Search by keyword or filter

Use the search box or filters (insurance, location, specialty, etc.) — e.g. Bronx, Aetna, DBT. Make sure provider descriptions include words staff will search.

🔍 Bronx  + filters → insurance, specialty, session format
2

Limit who can edit

Only 1–2 editors should have the Editor login — too many editors makes changes harder to track and easier to mix up. Editors keep the list accurate and up to date, and try to incorporate feedback from staff.

🔒 Editor login → add / edit / remove providers
3

Keep descriptions clean

Staff cannot edit the directory directly. Editors add updates at the top of Description — include the info, who contributed it, and the date.
